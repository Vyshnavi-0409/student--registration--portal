# 🎓 Student Registration & Result Portal

A responsive **Student Registration & Result Portal** built as a front-end mini project to demonstrate HTML5 form handling, HTML5 validation, and CSS3 / Bootstrap styling. Students can register their details, select a course, enter subject marks, and instantly view a generated result/mark sheet.

Two versions are included:
- **Custom HTML5 + CSS3** version (`student-result-portal.html`) — hand-built responsive layout using Flexbox/Grid
- **HTML5 + Bootstrap 5** version (`bootstrap-version.html`) — built using Bootstrap's grid, form, and component classes

---

## 📌 Project Objective

Build a responsive Student Registration & Result Portal where students can:
1. Enter their personal details
2. Select a course
3. Enter marks for different subjects
4. View the entered student details and marks in a structured, styled result sheet
5. Get guided data entry using HTML5 built-in validation attributes
6. Experience a polished, responsive layout on any screen size

---

## 🛠️ Technologies Used

| Technology     | Purpose                                                                 |
|----------------|--------------------------------------------------------------------------|
| **HTML5**      | Page structure, form, input fields, and result table                    |
| **CSS3**       | Styling, responsive layout, cards, tables, alerts (custom version)      |
| **Bootstrap 5**| Grid system, prebuilt form/table/card/alert components (Bootstrap version) |
| **JavaScript** | Form validation trigger, dynamic result calculation, and display        |

---

## ✨ Features

- ✅ HTML5 native validation — `required`, `pattern`, `type`, `min`/`max`
- ✅ Personal details form (Name, Roll No, DOB, Email, Phone)
- ✅ Course selection dropdown
- ✅ Marks entry for 5 subjects (out of 100 each)
- ✅ Auto-calculated **total, percentage, grade (O/A+/A/B/C/D/F)**
- ✅ Pass/Fail status per subject and overall result
- ✅ Fully responsive — works on mobile, tablet, and desktop
- ✅ Clean "mark sheet" style result display

## ▶️ How to Run

No installation or server required — this is a pure front-end project.

1. Clone or download this repository
   ```bash
   git clone https://github.com/<your-username>/student-result-portal.git
   ```
2. Open either HTML file directly in your browser:
   - `student-result-portal.html` (custom CSS3 design)
   - `bootstrap-version.html` (Bootstrap design)
3. Fill in the registration form and click **Submit & View Result** to see the generated result sheet.
